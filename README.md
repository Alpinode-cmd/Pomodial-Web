# Pomodial Web

添付されたSwiftUI製Pomodialをもとに移植した、依存ライブラリなしの日本語・英語対応PWAです。

## v3: ナビゲーションのレスポンシブ表示修正

- 画面幅ではなくアプリ本体の横幅を基準として下部タブバーを配置します。PCの広い画面でも3つのタブを均等に中央揃えします。
- 下部メニューに3等分のCSS Gridを採用し、アイコン・ラベルが重ならないよう調整しました。
- 言語設定・既存のタイマー設定・作業履歴は変更ありません。旧版からの更新時は公開先のファイル一式を上書きしてください。
- 古いレイアウトが残っている場合はブラウザを更新するか、ホーム画面から一度終了して再起動してください。Service Workerのキャッシュ名を更新しています。

## 表示言語の切り替え（日本語 / English）

1. 下部の「ガイド / Guide」タブを開きます。
2. 最上部の「言語 / Language」セクションにある「表示言語 / Display language」から「日本語」または「English」を選びます。
3. タイマー・統計・設定・通知テキストがすぐに切り替わります。選択は `localStorage` に保存され、次回起動時も維持されます。

既存のPomodial Web v1から更新する場合、同じURL・同じブラウザの保存領域を引き継げば、タイマー設定と履歴はそのまま残ります。Service Workerのキャッシュ識別子を更新済みです。公開先に全ファイルを上書きして、必要ならアプリを再読み込みしてください。

## 機能

- ポモドーロサイクル（作業 → 休憩 → 作業 → ... → 長い休憩）
- ダイヤル操作（停止中にポインタやタッチで回して1〜60分に調整）
- 開始、一時停止、再開、スキップ、リセット
- 終了時の自動フェーズ切替
- 画面を離れたりリロードした後も日時ベースで経過時間を復元
- localStorageへの設定・履歴保存、日別/週別統計、バックアップJSON書出/取込
- 元のiOSアプリ付属の効果音6種類
- 日本語 / English のアプリ内切り替え（言語設定の永続保存、各種表示・通知・モーダル・グラフ・効果音名に反映）
- ダークモード、画面点灯保持（対応ブラウザ）、ホーム画面追加、Service Workerによるキャッシュ

## 起動方法

静的ファイルだけで動作します。ターミナルでこのディレクトリを開き、次を実行してください。

```bash
python3 -m http.server 8000
```

Macで `http://localhost:8000/` を開いてください。

### iPhoneで使うには

1. このフォルダの内容をHTTPS対応の静的ホスティング（GitHub Pages / Cloudflare Pages / Netlify など）へ配置する。
2. iPhoneのSafariで公開URLを開く。
3. Safariの「共有」→「ホーム画面に追加」を選択する。

ローカルの `localhost` はMac自身を指すため、iPhoneからはMacのlocalhost URLに接続できません。ホーム画面追加やService WorkerはHTTPSでの配信を推奨します。

## iOS版からの主な制限

- Family Controlsや他のアプリの起動/使用制限はWebから操作できません。なお、添付されたPomodialのコードにFamily Controlsは含まれていません。
- タブを閉じた後やiPhoneでバックグラウンドになった時は、ブラウザーのJavaScriptが停止・制限される場合があります。残り時間と作業記録は次回起動時に絶対時刻から再計算されますが、音・バイブレーション・通知を端末のロック中まで確実に発火させることはできません。
- サーバーからのWeb Push通知は実装していません。iOS 16.4以降のホーム画面WebアプリはWeb Pushに対応しますが、プッシュ配信サーバーが別途必要です。
- Web Audioを含む音再生にはブラウザーの自動再生制限があります。試聴などのユーザー操作後は改善しますが、再生保証はありません。
- バイブレーションは対応ブラウザーのみ。Safari/iOSでは動作しないことがあります。
- iOSネイティブ版のファイルからのカスタム通知音インポートは未移植です。
- ブラウザーのローカル保存領域は削除されることがあるため、大事なデータはJSONの書き出しで保管してください。

## ディレクトリ

- `index.html`: 画面
- `styles.css`: スタイル
- `app.js`: タイマー・統計・設定・言語変更処理
- `i18n.js`: 日本語 / 英語の翻訳データ
- `manifest.webmanifest`, `sw.js`: PWA
- `assets/sounds`: 元アプリに同梱された WAV 6種類
- `assets/icons`: 元アプリのアイコンから縮小したPNG
